# FAUNAVET

Sitio web institucional y académico para una organización veterinaria ficticia dedicada a la atención, rehabilitación y conservación de la fauna silvestre.

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
```
